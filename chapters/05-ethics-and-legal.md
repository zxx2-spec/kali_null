# Chapter 5 — Ethics and legal notes

## What this tool does

- Reads public metadata for public IP addresses.
- Uses free, public APIs.
- Does not bypass authentication.
- Does not access private accounts.
- Does not track people.

## What it does NOT do

- It does not find a person's home.
- It does not reveal identity.
- It does not work on private IPs.
- It does not work through VPNs.

## Legal notes

- Querying public APIs is legal in most jurisdictions.
- Using the output to harass, stalk, or dox someone is illegal.
- The author assumes no liability for misuse.

## Responsible use

**Use it to:**
- Understand how IP geolocation works.
- Debug your own network.
- Learn API integration in Python.

**Do not use it to:**
- Target individuals.
- Bypass privacy protections.
- Harass or stalk.
